# Renewable_energy_microgrid
This is the masters thesis work of Timothy and Goodnews. The project entails modelling of the electric energy sources and the determination of the optimal capacity of renewable energy sources for the Ashesi University campus based on load constraints and cost.
The main sections in this project include the following:

  1. Existing solar photovoltaic power output modelling and optimization to determine the optimal additional capacity of solar photovoltaic installation based on some constraints.
  2. Battery energy storage system modelling and determination of optimal BESS scheduling and capacity based on some constraints.
  3. Probabilistic grid outage modelling with monte_carlo simulations.
  4. Economic Analysis of results.
